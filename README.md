# مصمم أثاث الكونتر 3D (Counter-Wood Furniture Designer)

تطبيق ويب تفاعلي ثلاثي الأبعاد (RTL) لتصميم قطع الأثاث من خشب الكونتر الطبيعي، مصمم للعمل بسلاسة على التابلت (باللمس والقلم) والكمبيوتر.

## المميزات الحالية (MVP)

- **مساحة عمل 3D احترافية:** إضاءة استوديو ناعمة وظلال واقعية، وشبكة أرضية مقسمة بالسنتيمتر (كل مربع = `10 سم`).
- **تحكم سلس بالكاميرا:** `OrbitControls` مع دعم اللمس وأزرار سريعة لزوايا الرؤية (`3D`، `أمامي`، `جانبي`، `علوي`).
- **إضافة ألواح جاهزة بضغطة زر:** قرصة/لوح أفقي (`100×40×1.8 سم`)، جنب/لوح رأسي (`40×80×1.8 سم`)، رف داخلي (`96.4×38×1.8 سم`)، وضهر (`0.6 سم`).
- **لوحة خصائص كاملة:** تعديل المقاسات بالسنتيمتر (`+ / -` أو إدخال مباشر)، تغيير السُمك السريع (`18 مم` / `6 مم`)، تدوير `90°` على محاور `X / Y / Z`، اختيار الخامة واللون (أبيض، أسود، رمادي، أرو فاتح، جوز غامق)، ونسخ/حذف اللوح.
- **التحريك والمغناطيس الذكي (Snapping):** تحريك ثلاثي الأبعاد عبر `TransformControls` بخطوات `0.5 سم`، مع الالتصاق التلقائي بالأرضية (`Y = 0`) وبأسطح وحواف الألواح المجاورة.
- **التراجع والحفظ:** `Undo / Redo` (حتى 50 خطوة) وحفظ واسترجاع أكثر من تصميم بالاسم عبر `localStorage`.

## التقنيات المستخدمة

- React + TypeScript + Vite
- Three.js (`@react-three/fiber` و`@react-three/drei`)
- Zustand لإدارة الحالة
- Tailwind CSS v4 + `lucide-react`

## التشغيل والتطوير

```bash
npm install

```
